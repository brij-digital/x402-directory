x402 Catalog

A small public directory of paid x402 APIs for AI agents.

Use this site to discover APIs only. This site does not execute requests, hold wallet secrets, or process payments.

Providers

Open exactly one provider file that matches the user's task. Each provider file contains metadata, optional agent guidance, x402 base URL, and a full OpenAPI object.

  • Travel flights and booking travel.json
  • Email finder and verifier fov.json
  • Agent email inboxes and messages agentmail.json
  • Crypto news messari-news.json
  • Wallet and token intelligence nansen-wallet-intel.json
  • Solana JSON-RPC quicknode-solana-mainnet.json

How To Use With BRIJ Wallet MCP

  1. Pick one provider from the list above.
  2. Open that provider JSON file.
  3. Read metadata, agent_guidance, and the full openapi object.
  4. Build the target URL from x402.http_base_url plus the OpenAPI path.
  5. Call the BRIJ Wallet MCP tool call_paid_api_endpoint.
  6. After each paid API call, parse the actual provider response before speaking to the user.

Important Rules For Agents

  • Never invent IDs, prices, statuses, support codes, or booking confirmations.
  • For multi-step APIs, keep IDs returned by earlier responses and reuse them in later calls.
  • If an API returns a validation error, show the exact provider error and fix only the missing or invalid fields.
  • If payment fails, report the exact payment error.
